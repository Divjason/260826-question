QUESTION 01 · 객관식

자료구조의 특징

정답 : ④

Set은 데이터의 입력 순서를 기준으로 인덱스를 이용하여 요소에 접근하는 자료구조가 아닙니다.

해설

List와 Tuple은 순서가 있는 Sequence 계열 자료구조이므로 인덱스를 이용하여 요소에 접근할 수 있습니다. 

data = ["A", "B", "C"]

print(data[0])

# A

반면 Set에서는 다음과 같은 인덱스 접근을 사용할 수 없습니다.

data = {"A", "B", "C"}

print(data[0])

# TypeError 발생
Set의 핵심

중복된 요소를 허용하지 않으며, List처럼 위치 번호를 이용해 요소를 꺼내는 자료구조가 아닙니다.
QUESTION 02 · 객관식

List

정답 : ② [10, 100, 30, 40]
data = [10, 20, 30, 40]

data[1] = 100

print(data)

해설

Python의 인덱스는 0부터 시작합니다. 

data = [10, 20, 30, 40]

         ↑   ↑   ↑   ↑
index    0   1   2   3

따라서:

data[1] = 100

은 두 번째 값인 20을 100으로 변경합니다.

List는 Mutable, 즉 생성된 이후에도 요소를 변경할 수 있는 자료구조입니다.
QUESTION 03 · 객관식

Tuple

정답 : ② data = (10,)

해설

요소가 하나뿐인 Tuple을 만들 때는 값 뒤에 반드시 쉼표 ,가 필요합니다. 

data = (10,)

print(type(data))

# <class 'tuple'>

반면 다음 코드는 Tuple이 아닙니다.

data = (10)

print(type(data))

# <class 'int'>
Tuple을 결정하는 핵심은 단순히 괄호 ()가 아니라 쉼표(comma)입니다.
QUESTION 04 · 객관식

Dictionary

정답 : ④ Python
student = {
    "name": "David",
    "age": 25,
    "course": "Python"
}

print(student["course"])

해설

Dictionary는 Key : Value 형태로 데이터를 저장합니다.

Key Value
name David
age 25
course Python

따라서:

student["course"]

는 "course"라는 Key에 연결된 Value인 Python을 반환합니다.

QUESTION 05 · 객관식

Set

정답 : ② 중복된 값이 제거되어 1, 2, 3만 요소로 남는다. 
numbers = {1, 2, 2, 3, 3, 3}

print(numbers)

해설

Set은 동일한 값을 여러 번 저장하지 않습니다.

{1, 2, 2, 3, 3, 3}

        ↓

중복 제거

        ↓

{1, 2, 3}
Set의 출력 순서를 전제로 프로그램을 작성하면 안 됩니다. 이 문제에서는 어떤 요소가 남는지가 핵심입니다.
QUESTION 06 · 주관식

List 작성하기

모범답안
fruits = ["apple", "banana", "orange"]

fruits.append("grape")

fruits.insert(1, "mango")

fruits.remove("banana")

print(fruits)

최종 결과:

['apple', 'mango', 'orange', 'grape']

실행 과정

["apple", "banana", "orange"]

        ↓ append("grape")

["apple", "banana", "orange", "grape"]

        ↓ insert(1, "mango")

["apple", "mango", "banana", "orange", "grape"]

        ↓ remove("banana")

["apple", "mango", "orange", "grape"]
메서드 기능
append() 마지막에 요소 추가
insert() 원하는 위치에 요소 삽입
remove() 지정한 값을 찾아 삭제
QUESTION 07 · 주관식

Tuple 이해하기

모범답안

① "green" 출력:

colors = ("red", "green", "blue")

print(colors[1])

결과:

green

② 다음 코드는 오류가 발생합니다.

colors[1] = "yellow"

왜 오류가 발생할까?

Tuple은 Immutable 자료구조이기 때문입니다.

Immutable은 생성된 이후 내부 요소를 직접 변경할 수 없다는 의미입니다. 

List
[10, 20, 30]
      ↓
요소 변경 가능


Tuple
(10, 20, 30)
      ↓
요소 직접 변경 불가능

실제 Python에서는 TypeError가 발생합니다.

QUESTION 09 · 주관식

Set 활용하기

모범답안
campaign_a = {101, 102, 103, 104}

campaign_b = {103, 104, 105, 106}

① 두 광고 중 하나 이상을 클릭

campaign_a | campaign_b

합집합 — Union 

{101, 102, 103, 104, 105, 106}

② 두 광고를 모두 클릭

campaign_a & campaign_b

교집합 — Intersection 

{103, 104}

③ Campaign A만 클릭

campaign_a - campaign_b

차집합 — Difference 

{101, 102}
연산 이름 의미
A | B Union A 또는 B
A & B Intersection A와 B 모두
A - B Difference A에는 있지만 B에는 없음
QUESTION 10 · 종합 주관식

상황에 맞는 자료구조 선택

A → List

장바구니 상품은 순서가 중요하고, 상품의 추가 및 삭제가 필요하므로 List가 적절합니다. 

cart = [
    "아메리카노",
    "카페라떼",
    "바닐라라떼"
]
B → Dictionary

상품명, 가격, 카테고리처럼 각 데이터가 무엇을 의미하는지 구분하여 저장해야 하므로 Dictionary가 적절합니다. 

product = {
    "name": "아메리카노",
    "price": 3000,
    "category": "Coffee"
}
C → Set

고객 ID에서 중복된 값을 제거하여 고유한 고객만 관리해야 하므로 Set이 적절합니다. 

customers = {
    101,
    102,
    102,
    103,
    103,
    104
}

print(customers)

남는 요소:

{101, 102, 103, 104}
D → Tuple

RGB는 Red, Green, Blue라는 값의 순서가 의미를 가지면서, 고정된 하나의 데이터 묶음으로 사용할 수 있으므로 Tuple이 적절합니다. 

rgb = (255, 128, 0)

자료구조 핵심 비교

자료구조 표현 순서 중복 변경 대표 활용
List [ ] O O O 장바구니
Tuple ( ) O O X 고정 데이터
Dictionary {Key: Value} 삽입 순서 유지 Key 중복 X O 상품 정보
Set { } 인덱싱 X X O 고유 고객

이번 수업의 핵심

List
순서가 중요하고 데이터를 추가·삭제·수정해야 할 때

Tuple
순서가 중요하면서 데이터를 변경하지 않을 때

Dictionary
데이터의 의미를 Key : Value 관계로 표현해야 할 때

Set
중복을 제거하거나 집합 간의 관계를 계산해야 할 때
