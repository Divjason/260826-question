QUESTION 01

Python 언어의 특징

다음 중 Python에 대한 설명으로 가장 적절하지 않은 것은?

정답 : ④
해설
Python에서는 일반적인 변수를 만들 때 변수 앞에 int, str 등의 자료형을 반드시 작성할 필요가 없습니다. 
age = 20
name = "Python"
Python은 실행 과정에서 값에 따라 자료형을 판단할 수 있습니다.
QUESTION 02

변수와 값 할당

price = 3000
price = 4500
price = price + 500
정답 : ③ 5000
해설
변수에는 새로운 값을 다시 저장할 수 있습니다. 
price = 3000

price = 4500

price = price + 500
마지막 코드에서 현재 값인 4500 + 500이 계산되므로 최종적으로 price에는 5000이 저장됩니다.
QUESTION 03

자료형(Data Type)

다음 중 자료형 연결이 잘못된 것은?

정답 : ④ "100" → int
해설
"100"은 숫자처럼 보이지만 따옴표로 감싸져 있기 때문에 문자열(String)입니다. 
print(type(100))
# int

print(type("100"))
# str
따라서 "100"의 자료형은 int가 아니라 str입니다.
QUESTION 04

사칙연산자

a = 10
b = 3

print(a + b)
print(a * b)
print(a / b)
정답 : ② 13, 30, 약 3.333...
해설
각각의 연산 결과는 다음과 같습니다. 
10 + 3
# 13

10 * 3
# 30

10 / 3
# 3.333333...
특히 Python에서 /는 일반적인 나눗셈 연산자이며, 결과가 실수(float) 형태로 반환됩니다.
QUESTION 05

비교연산자

age = 20

print(age > 18)
print(age == 20)
print(age != 20)
정답 : ① True, True, False
해설
20 > 18
# True

20 == 20
# True

20 != 20
# False
비교연산의 결과는 True 또는 False로 나타납니다.
QUESTION 06

변수 선언 및 출력

모범답안 
name = "홍길동"
age = 25

print(name)
print(age)
핵심 개념
문자열은 따옴표를 사용하고, 숫자는 따옴표 없이 변수에 저장할 수 있습니다.
※ 이름과 나이는 자유롭게 설정할 수 있으므로 변수와 출력 구조가 올바르면 정답으로 볼 수 있습니다.
QUESTION 07

형변환

모범답안 
price = "5000"
count = 3

total = int(price) * count

print(total)
핵심 개념
"5000"은 문자열이므로 int()를 사용하여 정수(Integer)로 변환합니다. 
int("5000")
# 5000
이후 숫자 3과 곱하면 15000을 얻을 수 있습니다.
QUESTION 08

input() 활용

모범답안 
name = input("이름을 입력하세요: ")

print("안녕하세요", name + "님!")
핵심 개념
input()은 사용자로부터 값을 입력받는 Python 내장함수입니다. 입력받은 값을 name 변수에 저장한 후 print()를 이용해 출력합니다.
QUESTION 09

입력값 + 형변환 + 연산

모범답안 
price = int(input("상품 가격을 입력하세요: "))
count = int(input("구매 수량을 입력하세요: "))

total = price * count

print("총 구매금액:", total)
핵심 개념
input()으로 입력받은 값은 기본적으로 문자열(str)이므로 계산을 위해 int()로 변환합니다. 
입력
↓
input()
↓
문자열(str)
↓
int()
↓
정수(int)
↓
곱셈
↓
총 구매금액
QUESTION 10

종합 문제

모범답안 
age = int(input("현재 나이를 입력하세요: "))

future_age = age + 10

print("10년 후 나이는", future_age, "살입니다.")
핵심 개념
이 문제는 첫날 학습한 여러 개념을 한 번에 확인하는 문제입니다. 
input()
↓
사용자 입력
↓
int()
↓
정수 변환
↓
변수 저장
↓
+ 연산
↓
새로운 변수에 결과 저장
↓
print()
※ 주관식 코드는 여러 가지 방식으로 작성할 수 있습니다. 실행 결과와 요구 조건을 만족한다면 위 모범답안과 코드가 완전히 동일하지 않아도 됩니다.
