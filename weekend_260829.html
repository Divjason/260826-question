STEP 01

카페 메뉴 만들기

다음과 같은 메뉴와 가격 정보를 리스트에 저장하세요.

menus = ["아메리카노", "카페라떼", "바닐라라떼"]

prices = [3000, 4000, 4500]

그리고 for문과 range()를 이용하여 메뉴를 출력하세요.

실행 예:

===== Python Cafe =====

1. 아메리카노 : 3000원
2. 카페라떼 : 4000원
3. 바닐라라떼 : 4500원

조건

  • 리스트를 사용하세요.
  • for 반복문을 사용하세요.
  • range()를 사용하세요.
  • 리스트 인덱스를 활용하세요.
STEP 02

주문받기

사용자에게 메뉴 번호와 주문 수량을 입력받으세요.

메뉴 번호를 선택하세요: 2

수량을 입력하세요: 3

input()을 사용하여 입력받고, 계산할 수 있도록 적절한 자료형으로 변환하세요.

힌트: input()으로 입력받은 값은 기본적으로 문자열입니다.

STEP 03

주문금액 계산하기

사용자가 선택한 메뉴의 가격과 주문 수량을 이용하여 총 주문금액을 계산하세요.

예를 들어 카페라떼를 3잔 주문했다면:

선택 메뉴 : 카페라떼

주문 수량 : 3잔

주문금액 : 12000원

사용자가 선택하는 메뉴 번호는 1부터 시작하지만, Python 리스트의 인덱스는 0부터 시작한다는 점에 주의하세요.

STEP 04

할인 조건 적용하기

총 주문금액이 10,000원 이상이면 10% 할인을 적용하세요.

10,000원 미만이라면 할인하지 않습니다.

예:

주문금액 : 12000원

할인금액 : 1200원

최종금액 : 10800원

할인 대상이 아니라면:

주문금액 : 6000원

할인 대상이 아닙니다.

최종금액 : 6000원

조건: if / else를 사용하세요.
