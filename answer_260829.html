STEP 01

카페 메뉴 만들기

메뉴와 가격을 각각 리스트로 만들고, for 반복문을 이용하여 출력합니다. 
menus = [
    "아메리카노",
    "카페라떼",
    "바닐라라떼"
]

prices = [
    3000,
    4000,
    4500
]


for i in range(len(menus)):

    print(
        i + 1,
        ".",
        menus[i],
        ":",
        prices[i],
        "원"
    )
실행 결과 
1 . 아메리카노 : 3000 원
2 . 카페라떼 : 4000 원
3 . 바닐라라떼 : 4500 원

핵심 포인트

len(menus)의 결과는 메뉴의 개수인 3입니다. 

len(menus)

# 3

따라서:

range(len(menus))

↓

range(3)

↓

0, 1, 2

이 값들은 그대로 리스트의 인덱스로 사용할 수 있습니다.

STEP 02

주문받기

input()과 int()를 사용합니다.
menu_number = int(
    input("메뉴 번호를 선택하세요: ")
)

count = int(
    input("수량을 입력하세요: ")
)

왜 int()가 필요한가?

input()으로 입력받은 값은 기본적으로 문자열입니다.

menu_number = input("메뉴 번호: ")

# 사용자가 2 입력

# 실제 값
"2"

메뉴 번호를 이용하여 계산하거나 인덱스를 찾으려면 숫자로 변환하는 것이 필요합니다. 

int("2")

# 2
STEP 03

선택 메뉴와 주문금액 계산

사용자가 입력한 메뉴 번호에서 1을 빼서 리스트 인덱스로 사용합니다. 
selected_menu = menus[menu_number - 1]

selected_price = prices[menu_number - 1]

total = selected_price * count

왜 menu_number - 1일까?

사용자에게 보여주는 메뉴 번호는 1부터 시작합니다.

1. 아메리카노
2. 카페라떼
3. 바닐라라떼

하지만 Python 리스트의 인덱스는 0부터 시작합니다.

menus[0] → 아메리카노

menus[1] → 카페라떼

menus[2] → 바닐라라떼

예를 들어 사용자가 2번을 선택하면:

menu_number = 2

menu_number - 1

↓

1

↓

menus[1]

↓

"카페라떼"
중요

사용자에게 보여주는 번호와 Python의 인덱스 번호가 다르다는 것을 이해하는 것이 이 문제의 중요한 포인트입니다.
STEP 04

할인 조건 적용하기

주문금액이 10,000원 이상이면 10% 할인을 적용합니다. 
if total >= 10000:

    discount = total * 0.1

    final_price = total - discount

else:

    discount = 0

    final_price = total

예시

total = 12000

discount = 12000 * 0.1

# 1200


final_price = 12000 - 1200

# 10800

따라서:

주문금액 : 12000원

할인금액 : 1200원

최종 결제금액 : 10800원
STEP 05

할인 계산을 함수로 만들기

calculate_discount() 함수로 할인 계산 부분을 분리합니다. 
def calculate_discount(total):

    if total >= 10000:

        final_price = total * 0.9

    else:

        final_price = total


    return final_price

함수 호출:

final_price = calculate_discount(total)

함수의 흐름

total
  ↓
calculate_discount(total)
  ↓
if 조건 확인
  ↓
할인 계산
  ↓
return
  ↓
final_price

예를 들어:

total = 12000

final_price = calculate_discount(12000)

함수 안에서는:

12000 >= 10000

# True


12000 * 0.9

# 10800

따라서 최종적으로:

final_price = 10800

이 됩니다.

STEP 06 · CHALLENGE

while을 이용하여 반복 주문하기

while True와 break를 사용하면 사용자가 종료할 때까지 반복할 수 있습니다. 
while True:

    # 주문 코드


    answer = input(
        "계속 주문하시겠습니까? (yes/no): "
    )

    answer = answer.strip()


    if answer == "no":

        print("이용해주셔서 감사합니다.")

        break

while True의 의미

while True:

조건이 항상 True이므로 계속 반복됩니다.

따라서 반복을 끝내기 위한 break가 필요합니다. 

if answer == "no":
    break

사용자가 no를 입력하는 순간 반복문을 종료합니다.
