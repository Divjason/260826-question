QUESTION 01

문자열 함수와 메서드

함수(Function)와 메서드(Method)의 사용 방법이 올바르지 않은 것은?

정답 : ④ "Python".len()
해설
len()은 문자열에 붙여 사용하는 메서드가 아니라 값을 인자로 전달하는 함수입니다. 
len("Python")
# 6
반면 find(), count()는 문자열 객체에 붙여 사용하는 메서드입니다. 
"Python".find("t")

"banana".count("a")
따라서 다음 코드는 사용할 수 없습니다. 
"Python".len()
QUESTION 02

문자열 인덱스

text = "Python"

print(text[0])
print(text[2])
print(text[-1])
정답 : ① P, t, n
해설
Python 문자열의 인덱스는 0부터 시작합니다. 
문자   P  y  t  h  o  n
양수   0  1  2  3  4  5
음수  -6 -5 -4 -3 -2 -1
따라서 
text[0]
# P

text[2]
# t

text[-1]
# n
이 됩니다.
QUESTION 03

문자열 슬라이싱

text = "DataAnalysis"

print(text[0:4])
정답 : ① Data
해설
슬라이싱은 다음 형태로 사용합니다. 
문자열[시작 인덱스 : 끝 인덱스]
중요한 점은 끝 인덱스의 문자는 포함하지 않는다는 것입니다. 따라서 
text[0:4]
는 인덱스 0, 1, 2, 3에 해당하는 
Data
만 가져옵니다.
QUESTION 04

strip() 메서드

text = "###Python###"

print(text.strip("#"))
정답 : ② Python
해설
strip()은 문자열의 양쪽 끝에서 지정한 문자를 제거합니다. 
"###Python###".strip("#")

# Python
문자열 중간에 있는 문자까지 모두 삭제하는 것은 아닙니다. 예를 들어 다음 문자열에서 
"Py#thon".strip("#")
가운데 있는 #는 제거되지 않습니다.
QUESTION 05

리스트 메서드

fruits = ["apple", "banana"]

fruits.append("orange")
fruits.insert(1, "grape")
fruits.pop()

print(fruits)
정답 : ② ["apple", "grape", "banana"]
실행 과정
처음 리스트는 
["apple", "banana"]
입니다. append() 실행 후 
fruits.append("orange")

["apple", "banana", "orange"]
insert() 실행 후 
fruits.insert(1, "grape")

["apple", "grape", "banana", "orange"]
마지막으로 인자 없이 pop()을 실행하면 리스트의 마지막 요소가 삭제됩니다. 
fruits.pop()

["apple", "grape", "banana"]
QUESTION 06

문자열 count()

모범답안 
message = "Python is easy. Python is powerful."

print(message.count("Python"))
실행 결과
2
count()는 문자열에서 특정 문자열이 몇 번 등장하는지를 반환합니다. 
message.count("Python")
의 결과가 숫자 2이므로 print()를 사용하면 2가 출력됩니다.
QUESTION 07

find() + 슬라이싱

모범답안 
email = "student@gmail.com"

index = email.find("@")

print(email[:index])
핵심 개념
먼저 
email.find("@")
를 이용하여 @ 문자의 위치를 찾습니다. 그 위치를 index 변수에 저장한 후 
email[:index]
를 사용하면 문자열의 처음부터 @ 직전까지 가져올 수 있습니다. 결과는 
student
입니다. 이 문제의 핵심은 메서드의 반환값을 다른 코드에 다시 활용하는 것입니다.
QUESTION 08

리스트 조작

모범답안 
students = ["민수", "영희", "철수"]

students.append("지수")
students.insert(1, "준호")
students.remove("철수")

print(students)
실행 결과
["민수", "준호", "영희", "지수"]
각각의 메서드는 다음 역할을 합니다. 
append()
→ 리스트 마지막에 값 추가

insert()
→ 원하는 인덱스 위치에 값 추가

remove()
→ 지정한 값을 찾아 삭제
QUESTION 09

조건문 + and

모범답안 
age = 25
has_ticket = True

if age >= 20 and has_ticket == True:
    print("입장 가능합니다.")
핵심 개념
and는 양쪽 조건이 모두 True일 때만 전체 조건이 True가 됩니다. 
age >= 20
# True

has_ticket == True
# True

True and True
# True
따라서 실행문이 실행됩니다. 다음처럼 작성해도 올바른 코드입니다. 
if age >= 20 and has_ticket:
    print("입장 가능합니다.")
QUESTION 10

종합 문제

모범답안 
user_id = input("아이디를 입력하세요: ")

user_id = user_id.strip()

if user_id == "admin" or user_id == "manager":
    print("관리자입니다.")
else:
    print("일반 사용자입니다.")
코드 실행 흐름
input()
↓
사용자가 아이디 입력
↓
strip()
↓
앞뒤 공백 제거
↓
admin 또는 manager인지 비교
↓
or 연산
↓
if / else
↓
결과 출력
예를 들어 사용자가 
   admin
처럼 입력해도 
user_id.strip()
이후에는 
admin
이 되므로 관리자 조건을 만족합니다.
※ 주관식 코드는 위 모범답안과 완전히 같지 않아도 됩니다. 문제에서 요구한 함수와 연산자를 사용하고, 실행 결과가 올바르면 정답으로 판단할 수 있습니다.
