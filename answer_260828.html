QUESTION 01

for 반복문

for i in range(1, 5):
    print(i)
정답 : ② 1, 2, 3, 4

해설

range(1, 5)는 1부터 시작하지만 마지막 값인 5는 포함하지 않습니다. 

range(1, 5)

1
2
3
4

Python의 range()에서 종료값은 포함되지 않는다는 것이 핵심입니다.

QUESTION 02

range() 함수

for i in range(2, 10, 2):
    print(i)
정답 : ① 2, 4, 6, 8

해설

range()에는 시작값, 종료값, 증가값을 지정할 수 있습니다. 

range(시작값, 종료값, 증가값)

range(2, 10, 2)

따라서 2부터 시작하여 2씩 증가합니다.

2
4
6
8

종료값인 10은 포함되지 않습니다.

QUESTION 03

while 반복문

count = 1

while count <= 3:
    print(count)
    count = count + 1
정답 : ② 1, 2, 3

해설

처음에는 count = 1입니다.

count <= 3이라는 조건이 True인 동안 반복합니다.

count = 1 → 출력 1

count = 2 → 출력 2

count = 3 → 출력 3

count = 4 → 조건 False → 반복 종료

특히 다음 코드가 있기 때문에 무한 반복되지 않습니다.

count = count + 1
QUESTION 04

함수와 return

def add(a, b):
    result = a + b
    return result

number = add(10, 20)

print(number)
정답 : ③ 30

해설

add(10, 20)을 호출하면 10과 20이 각각 a, b로 전달됩니다. 

a = 10
b = 20

result = a + b

result = 30

이후:

return result

에 의해 30이 함수 밖으로 반환되고, 그 값이 number 변수에 저장됩니다. 

number = 30

print(number)

# 30

QUESTION 06

for + range()

모범답안
for i in range(1, 6):
    print(i)
실행 결과 
1
2
3
4
5

해설

5까지 출력하려면 종료값을 6으로 지정해야 합니다. 

range(1, 6)

종료값 6은 포함되지 않기 때문에 1부터 5까지 반복됩니다.

QUESTION 07

for + 누적 연산

모범답안
total = 0

for i in range(1, 11):
    total = total + i

print(total)
실행 결과 : 55

해설

total이라는 변수에 반복해서 값을 더하는 누적 연산입니다. 

처음 total = 0

0 + 1 = 1

1 + 2 = 3

3 + 3 = 6

6 + 4 = 10

...

45 + 10 = 55

따라서 마지막 total에는 55가 저장됩니다.

QUESTION 08

while 반복문

모범답안
count = 5

while count >= 1:
    print(count)
    count = count - 1
실행 결과 
5
4
3
2
1

해설

이번에는 변수를 증가시키는 것이 아니라 반복할 때마다 1씩 감소시킵니다. 

count = count - 1

따라서:

5 → 4 → 3 → 2 → 1 → 0

0이 되면 count >= 1이 False가 되어 반복문이 종료됩니다.

QUESTION 09

함수 작성

모범답안
def multiply(a, b):
    return a * b


result = multiply(5, 3)

print(result)
실행 결과 : 15

해설

함수에는 두 개의 매개변수 a, b가 있습니다. 

multiply(5, 3)

a ← 5
b ← 3

함수 내부에서:

a * b

5 * 3

15

를 계산하고 return을 이용하여 결과값 15를 함수 밖으로 반환합니다.

QUESTION 10

Git & GitHub 명령어

모범답안
git init

git add .

git commit -m "first commit"

git push

각 명령어의 역할

① git init 

git init

현재 폴더를 Git이 관리하는 로컬 저장소로 초기화합니다.

② git add . 

git add .

현재 변경된 파일들을 다음 Commit에 포함할 수 있도록 Staging Area에 추가합니다.

③ git commit 

git commit -m "first commit"

Staging Area에 추가된 변경 내용을 하나의 버전으로 기록합니다.

④ git push 

git push

로컬 Git 저장소의 Commit을 GitHub와 같은 원격 저장소로 전송합니다.

기본 흐름 
git init
    ↓
git add .
    ↓
git commit
    ↓
git push

※ 실제로 처음 GitHub 저장소에 연결하는 경우에는 git remote add origin ... 등의 추가 설정이 필요할 수 있습니다.
